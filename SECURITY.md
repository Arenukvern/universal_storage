# Security Policy

Storage sync, mesh transports, and OAuth adapters can touch credentials and
user data.

## Reporting a vulnerability

Report vulnerabilities privately to **anton@xsoulspace.dev**. Do not open a
public GitHub issue for an unpatched security problem.

Include steps to reproduce, affected package names, and impact if known. We
will acknowledge receipt and coordinate a fix and disclosure timeline.

## Supported versions

Only the latest `main` branch and the most recent published package versions
on pub.dev receive security fixes during the `0.1.0-dev` alpha unless noted in
release notes.

# Principles and ethics

Universal Storage is built with the same engineering ethics as the author's
other open work ([Skill Steward](https://github.com/Arenukvern/skill_steward),
[mcp_flutter](https://github.com/Arenukvern/mcp_flutter)).

## Tagline

**Care · Innovation · Empirical self-evolution**

We optimize for people who depend on their data for years, not for a single
vendor demo.

## Care

- **Users own the data** — formats and APIs should be inspectable; encryption
  and export paths are first-class, not upsell gates.
- **Builders deserve honest docs** — claims match the weakest proof in CI;
  alpha status is labeled until conformance and migration suites say otherwise.
- **Agents are collaborators** — `AGENTS.md`, Skill Steward, and clear docs
  maps reduce thrash for human and agent contributors alike.

## Innovation

- **Migration by default** — moving between backends is a product feature, not
  a one-off script.
- **Efficiency as a feature** — chunking, dedup, compression, and lazy I/O are
  pluggable; benchmarks exist to prevent silent regressions.
- **Right horizon** — multi-device sync for one user comes before shared
  live-world MMO-style state.

## Empirical self-evolution

- **Conformance over assertion** — backends prove behavior in
  `universal_storage_conformance`, not in prose.
- **Benchmarks and chaos tests** — git migration and outbox suites catch real
  races; informational benchmarks stay tagged and optional in CI.
- **Release legibility** — release-please, changelogs, and pub dry-runs keep
  versions aligned with what ships.
